텔레그램 연결 순서

  1. 봇 만들기. 텔레그램에서 @BotFather를 열고 /newbot으로 이 플러그인 전용 봇을 만드세요. 채널에 추가할 때 쓸 봇의 @사용자명을 확인합니다.
  2. 토큰 복사. 생성 완료 메시지에서 HTTP API 아래에 있는 1234567890:AA… 형식의 문자열 전체를 ‘전용 봇 토큰’에 붙여 넣으세요. 이미 만든 봇은 /mybots → 해당 봇 → API Token에서 확인할 수 있습니다.
  3. 채널에 봇 추가. 링크를 올릴 채널의 채널 관리(편집) → 관리자 → 관리자 추가에서 봇의 @사용자명을 검색해 등록하세요.
  4. 채널 지정. 공개 채널은 채널 자체의 @사용자명을 입력하세요. 비공개 채널은 게시물을 우클릭하거나 길게 눌러 메시지 링크 복사를 선택하세요. 예를 들어 https://t.me/c/1234567890/5에서 채널 번호는 1234567890, 입력할 ID는 -1001234567890입니다. 마지막 5는 게시물 번호입니다. 채널 ID 계산식은 −(1,000,000,000,000 + 채널 번호)입니다. t.me/+…는 초대 링크이므로 사용할 수 없습니다.
  5. 설정 저장과 확인. 위 복사 설정에서 기본 Remote를 먼저 저장하세요. 채널 링크 자동 수신 사용 → 텔레그램 설정 저장 → 채널 연결 확인 순서로 누르면 연결된 봇과 대화방이 표시됩니다.
  6. 첫 링크 수신. 해당 채널에 Google Drive 폴더 링크를 새로 올리고 링크 지금 확인을 누르세요. 다운로드 목록에서 ‘텔레그램’으로 등록된 작업과 최종 복사 경로를 확인할 수 있습니다. 자동 수신이 먼저 처리했다면 지금 확인 결과는 신규 0건으로 표시됩니다.
