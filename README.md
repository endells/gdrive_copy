# 구글 드라이브 개별 복사 0.1.1

Google Drive 폴더 링크나 ID를 받아 FF의 rclone 리모트에 원본 폴더명으로 복사하는 FlaskFarm 플러그인입니다. 수동 요청과 텔레그램 요청은 같은 다운로드 목록에 기록됩니다.

## 시놀로지에서 설치

1. FF의 **시스템 → 플러그인 → 로딩 플러그인**에서 **플러그인 설치** 입력란을 엽니다.
2. 아래 주소를 그대로 붙여 넣고 **설치**를 누릅니다.

   ```text
   https://github.com/endells/gdrive_copy
   ```

3. 설치 완료 후 FF를 재시작하고 **구글 드라이브 개별 복사 → 설정**을 엽니다.

이전에 ZIP으로 설치했다면 FF를 중지하고 기존 `plugins/gdrive_copy` 폴더를 `plugins` 바깥에 백업한 뒤 FF를 시작해 위 절차를 진행하세요. 설정과 이력은 FF 데이터 폴더의 `db/gdrive_copy_queue.db`에 보관됩니다.

## 첫 복사

1. 기본 Remote에 `endells_gg:/FF/`를 저장합니다. 소스 리모트는 같은 계정을 사용하면 비워 두세요. 다른 계정에만 원본 읽기 권한이 있다면 해당 Google Drive OAuth 리모트 이름을 입력합니다.
2. **개별 요청**에 전체 공유 링크를 붙여 넣습니다. **폴더·크기 확인**을 누르면 원본 제목, 소스 ID, 파일 수, 총 크기, 최종 경로가 표시됩니다.
3. **복사 요청**을 누릅니다. **다운로드 목록**에서 대기·진행 중·완료·실패 상태와 경로를 확인합니다. 실패 사유는 목록과 **로그**에 한국시간으로 기록됩니다.

예를 들어 원본 제목이 `하이큐!! 쓰레기장의 결전 (2024)`이면 대상은 `endells_gg:/FF/하이큐!! 쓰레기장의 결전 (2024)/`입니다. 원본의 파일과 하위 폴더가 그 안에 들어갑니다. 기본 Remote에는 작품명을 붙일 필요가 없습니다. 요청 화면에서 바꾼 Remote는 해당 요청에만 적용됩니다.

지원 입력은 소스 ID, `https://drive.google.com/drive/folders/ID`, 계정 선택 경로 `/drive/u/0/folders/ID`, `/open?id=ID`입니다. `hl`, `usp` 등은 무시하고 `resourcekey`가 있으면 직접 복사에서 사용합니다. 파일 단독 링크는 지원하지 않습니다.

## 복사 방식

| 설정 | 사용할 때 | 준비 |
| --- | --- | --- |
| rclone 직접 복사 (기본) | 소스 리모트 계정에서 공유 폴더를 열 수 있을 때 | Google Drive OAuth 소스 리모트, 쓰기 가능한 대상 리모트 |
| 기존 구드공 워커 연동 | 기존 구드공에서 처리하던 요청을 워커로 보낼 때 | 기존 `gds_tool` 및 구드공 이용 환경, 워커가 원본 ID에 접근할 권한 |

직접 복사는 FF rclone 플러그인에 등록된 실행 파일과 `rclone.conf`를 사용합니다. rclone 플러그인이 없으면 FF에서 실행 가능한 `rclone`과 FF 데이터 폴더의 `db/rclone.conf`를 사용합니다. 이 버전의 소스 이름 조회는 OAuth로 로그인한 `drive` 리모트를 사용합니다. 별도 복사 서버 설정이나 Google 토큰 재입력은 필요하지 않습니다. 동일한 Drive 리모트에서는 서버 측 복사를 요청합니다. 다른 계정·다른 종류의 리모트로 복사하면 NAS를 통해 전송할 수 있습니다.

구드공 연동에서는 개인 리모트로 폴더명을 확인하고, 실패하면 공개 공유 페이지의 제목을 조회합니다. 워커만 볼 수 있고 개인 계정과 공개 페이지 양쪽에서 제목을 읽을 수 없는 폴더는 실패로 기록됩니다. 구드공에는 원본 플러그인의 인터페이스에 맞게 소스 ID를 보냅니다. 리소스 키가 필수인 폴더에는 직접 복사를 사용하세요. 기존 구드공 목록에 같은 ID가 다른 목적지로 등록된 경우에는 충돌 내역을 먼저 확인하세요.

## 텔레그램 자동 수신

1. 텔레그램에서 [@BotFather](https://t.me/BotFather)를 열고 `/newbot`으로 수신 전용 봇을 만듭니다. 기존 문피아 다운로더 봇과는 별도 토큰을 사용합니다.
2. 완료 메시지의 **Use this token to access the HTTP API** 아래 한 줄이 **전용 봇 토큰**입니다. `1234567890:AA…`처럼 콜론으로 이어진 숫자와 뒷문자열 전체를 넣으세요. 기존 봇은 `/mybots` → 해당 봇 → **API Token**에서 확인할 수 있습니다.
3. 채널 관리(편집) → 관리자 → **관리자 추가**에서 봇의 `@사용자명`을 검색해 추가합니다. FF의 채널 입력란에는 공개 채널의 `@채널사용자명` 또는 비공개 채널의 숫자 ID를 넣습니다. 예를 들어 게시물 링크 `https://t.me/c/1234567890/5`의 채널 ID는 `-1001234567890`입니다. 계산식은 `−(1,000,000,000,000 + 채널 번호)`입니다.
4. 기본 Remote를 **복사 설정 저장**으로 저장한 뒤 **채널 링크 자동 수신 사용 → 텔레그램 설정 저장 → 채널 연결 확인**을 누릅니다. 연결 확인은 봇과 대화방을 조회하며 업데이트를 소비하지 않습니다. 토큰 입력란을 비워 저장하면 기존 토큰이 유지됩니다.
5. 해당 채널에 새 Google Drive 폴더 링크를 게시하고 **링크 지금 확인**을 누릅니다. 등록된 요청은 **다운로드 목록**에서 확인합니다. 자동 수신의 기본 주기는 1분입니다. 개인 대화에서는 먼저 봇에 메시지를 보내고 그룹에서는 봇이 일반 메시지를 읽을 수 있도록 설정하세요.

Telegram Bot API가 봇에 전달하는 새 업데이트를 처리합니다. 대화방의 과거 기록 전체를 가져오지는 않습니다. `getUpdates` 전용 봇을 사용하며 기존 웹훅이 설정되어 있으면 이유를 로그에 표시합니다. 토큰은 FF 데이터 폴더의 작업 DB에 저장되며 설정 화면에서 다시 표시하지 않습니다.

## 목록과 복구

- 동일 소스 ID와 기본 Remote 조합은 한 번만 등록합니다. 재복사는 목록의 **재요청**을 사용하세요.
- 기본 파일 수 한도는 요청당 500개입니다. 직접 복사는 설정에서 변경할 수 있고 구드공 연동에는 최대 1,000개 제한이 추가로 적용됩니다.
- 직접 복사는 빈 하위 폴더도 생성합니다. 제목의 한글, 띄어쓰기, 괄호는 유지하고 경로 구분 기호인 `/`는 rclone 경로에서 `／`로 표시합니다.
- 처음 복사할 때 같은 이름의 대상 폴더가 이미 있으면 중단합니다. 기존 폴더와 섞이지 않게 다른 기본 Remote를 선택할 수 있습니다. 같은 작업의 재요청은 기존 대상을 재사용합니다.
- FF를 재시작하면 대기 작업을 이어서 처리합니다. 중단된 직접 복사는 rclone이 이미 복사된 파일과 비교하면서 다시 실행됩니다. 구드공 연동은 등록된 워커 요청의 결과를 확인합니다.
- **목록 삭제**는 이력만 지웁니다. 진행 중인 작업은 목록에서 삭제할 수 없습니다. **로그** 화면에는 최근 200건을 표시합니다.
- 플러그인 소스를 업데이트할 때 기존 `db/gdrive_copy_queue.db`를 보존하세요. 설정, 텔레그램 수신 위치 및 복사 이력이 들어 있습니다.
